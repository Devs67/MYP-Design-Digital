# Icon placement list

Use one consistent 20–24 px outline set. Keep the text label beside every unfamiliar action.

- `home`: Home and brand return links
- `arrow-left`: Back to workspace and previous dialog
- `search`: Search controls and search dialog
- `users`: Design Team, class roster and group maker
- `sun` / `moon`: Light and Dark theme controls
- `external-link`: Resource links, framework links and downloads that leave the site
- `book-open`: Guides, frameworks and lesson resources
- `file-text`: Task sheets, briefs and templates
- `download`: PDF, template and export actions
- `save`: Teacher notes, progress and checklist save actions
- `copy`: Copy progress code
- `refresh-cw`: Refresh, restart and reload actions
- `trash-2`: Clear roster / destructive reset actions
- `check-circle`: Submit, addressed and completed states
- `grid`: Lesson cards, framework grid and resource overview

Icons belong in the button or list-row leading slot. Do not replace Criterion A–D labels, checklist text, or achievement bands with icons.
