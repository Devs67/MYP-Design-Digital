# Berry homepage export

This package contains the updated berry homepage only.

- Persistent Figma source: https://www.figma.com/design/FedM3qdAEpfkigDqWC4rom/MYP-Digital-Design-Reimagined?node-id=229-7359
- Desktop reference: ref-home-desktop.png, captured from the berry Figma frame at 1x.
- Mobile and strand screenshots are intentionally omitted because this export is limited to the updated homepage.
- tokens.css contains the light berry palette and typography tokens.
- components.css contains the homepage shell, glass cards, grid, cycle tiles, search field and responsive rules.
- The background SVGs are static export references; the fluid Flow motion from feralui.dev is a later implementation step.
- Icons are intentionally omitted. Use Lucide or the existing icon system.
- Only these elements use berry #A13C66: header year navigation, Design Team, Light/Dark, the three Enter MYP links and the three shared-resource action links.
- Card headings, hero headings, descriptions and the A–D overview remain neutral.
